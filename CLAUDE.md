# Working notes for Claude Code sessions on this repo

## PR review

Codex review does not always auto-trigger on PRs opened from this workflow's
branches. After opening a PR, check whether a Codex review shows up on its
own; if it doesn't, post a `@codex review` comment on the PR to invoke it
manually before waiting for it.

## After a merge

When reporting that a PR merged, end the message with two links: the PR
itself and the live viewer (https://sluborg.github.io/ArtLibrary/).
